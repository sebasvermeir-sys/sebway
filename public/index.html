Claude API key

The chat runs on your own Claude account. Your key is saved only on this device. It is sent with each chat message to Sebway's server, which passes it to Claude for that one request and never stores it. Usage is billed to your Anthropic account.

Get a key at console.anthropic.com.

Notifications

Sebway checks your saved routes every 5 minutes and alerts you only for strikes and major disruptions on them, and when a pass is about to run out. Never at night (23:00–07:00).

Privacy

Sebway has no accounts. This phone gets a random ID, and Sebway's server keeps only what you choose:

  • your saved routes, boards, passes and walking time;
  • your notification subscription, if you turn alerts on;
  • during a journey, that trip, for lock-screen updates and a link you share (deleted 1 hour after arrival).

Your location and chat history stay on this phone. Your Claude key stays on this phone too: it's passed to Claude with each chat message and never stored. Cloudflare, which hosts Sebway, keeps technical request logs (including places you searched) for a few days to fix errors.

Delete My Data removes everything Sebway's server has for this phone and resets the app here.
